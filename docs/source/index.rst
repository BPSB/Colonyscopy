Colonyscopy Documentation
=========================

Colonyscopy is a Python package for processes images of colonies arranged in a rectangular grid and analysing changes in colony intensity over time. 

It provides tools for automatic as well as interactive image cropping based on Fourier, artifact detection, colony detection and growth analysis using time-series images.
